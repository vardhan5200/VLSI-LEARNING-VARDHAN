# Working glossary

[Home](../README.md)

| Term | Meaning in this guide |
|---|---|
| ASIC | Application-specific integrated circuit |
| RTL | Register-transfer-level description of state and operations |
| HDL | Hardware description language |
| PPA | Power, performance, and area |
| PDK | Process design kit containing process-specific rules and models |
| Standard cell | Precharacterized reusable logic/storage layout block |
| Net | Electrical connection among pins |
| Netlist | Description of instances and their connections |
| Liberty | Cell-function, timing, and related characterization format |
| LEF | Physical abstract for technology/cells |
| DEF | Exchange format for design physical implementation information |
| GDSII | Hierarchical layout geometry format |
| SDC | Timing-constraint format using Tcl syntax |
| SPEF | Parasitic exchange format |
| Slew | Signal transition time |
| Fanout | Number of loads driven by a net |
| Setup | Required data stability before a capture edge |
| Hold | Required data stability after a capture edge |
| Slack | Margin between data timing and a timing requirement |
| CTS | Clock-tree synthesis |
| CDC | Clock-domain crossing |
| DFT | Design for test |
| ATPG | Automatic test-pattern generation |
| BIST | Built-in self-test |
| DRC | Design-rule checking |
| LVS | Layout versus schematic/netlist checking |
| ERC | Electrical-rule checking |
| ECO | Engineering change order |
| IR drop | Voltage loss caused by current through resistance |
| EM | Electromigration |
| WNS | Worst negative slack; report conventions should be checked |
| TNS | Total negative slack over the endpoints/groups a tool counts |
| MCMM | Multi-corner, multi-mode analysis |
