## Exercise 1

The gate-level netlist represents cell instances and connectivity. GDSII represents layout geometry/hierarchy. A timing library is neither: it models cell behavior and characteristics.

## Exercise 2

Possible causes include wire RC delay, unfavorable clock skew, and actual output loading or cell input slew that differs from assumptions. Also inspect missing or incorrect constraints. A logic-only simulation may have no realistic timing model at all.

## Exercise 3

Functional evidence: reset drives Q=0 on a rising edge; enable increments; disable holds; Q wraps 15→0. Include reset-plus-enable priority as an extra case. Implementation evidence: all relevant paths are constrained and meet required setup/hold limits; required physical/connectivity checks pass with explained exceptions. Archive actual reports and tool inputs.
