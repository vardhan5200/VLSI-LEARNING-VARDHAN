# Free practice tools and primary references

[Home](../README.md)

These official pages were checked on 9 September 2026. Installation requirements and supported commands can change; follow the documentation matching your installed version.

| Purpose | Official reference | First task |
|---|---|---|
| HDL simulation | [Icarus Verilog getting started](https://steveicarus.github.io/iverilog/usage/getting_started.html) | Compile and run the counter lab |
| Logic synthesis | [Yosys synthesis starter](https://yosyshq.readthedocs.io/projects/yosys/en/latest/getting_started/example_synth.html) | Explain the resulting netlist |
| Static timing | [OpenSTA](https://github.com/The-OpenROAD-Project/OpenSTA) | Learn required library, netlist, SDC, and parasitic inputs |
| Physical implementation | [OpenROAD documentation](https://openroad.readthedocs.io/en/latest/main/README.html) | Follow a supported example flow before adapting a design |
| Repository publishing | [GitHub CLI repo create](https://cli.github.com/manual/gh_repo_create) | Publish the prepared local project after authenticating |

Open-source tool availability does not mean every foundry PDK or cell library is freely redistributable. Use a supported, appropriately available platform and record its actual version. The learning package does not bundle a PDK, commercial library, or downloaded course videos.
