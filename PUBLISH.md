## Work locally

With Git installed, clone the repository and enter it:

```bash

cd VLSI-LEARNING-VARDHAN
```

Read [the lab instructions](labs/README.md) before running simulation or synthesis. Generated build outputs are ignored by Git; retain meaningful verification evidence deliberately when submitting a project.

## Add notes or corrections

Create a descriptive branch, edit the relevant chapter or solution, and commit the change. Keep lecture evidence distinct from independent examples. Use [the lecture template](templates/LECTURE-NOTE.md) when adding a verified video note.

Include the reason for a correction and a worked calculation, source, or test result supporting it. Preserve unrelated content. Never commit credentials, proprietary libraries, or copied course videos.

When a change affects RTL, rerun the applicable tests and record their actual outcome. When it changes chapter names or navigation, check relative links. Do not report an unexecuted tool stage as passed.
