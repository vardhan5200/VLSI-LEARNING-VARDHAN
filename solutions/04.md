## Exercise 2

With index = 4A+2B+C, the listed minterms all have C=0, and include every A,B combination. Therefore F=C'. The indexing statement matters because another bit order changes which variable is constant.

## Exercise 3

A likely cause is an output missing an assignment in an if/else or case branch. Provide a meaningful default and override it, or assign in every branch. Suppressing the warning preserves unintended storage and changes the design's behavior and timing. If a latch is actually required, document that specification and analyze its timing explicitly.
